What is Git?

Git is a distributed version control system used to track changes in source code. It allows developers to work on projects individually or as a team while maintaining the complete history of changes.

Benefits of Git
Tracks file history
Supports collaboration
Allows branching and merging
Helps recover previous versions
Makes code management easier

What is GitHub?
GitHub is a cloud platform that hosts Git repositories. It enables developers to store code online, collaborate with others, review code, and manage software projects.  


Understanding Remote Repositories
A remote repository is the online version of your local Git repository.

What is Origin?
origin is the default nickname for the remote GitHub repository.

What is Main?
main is the default branch of a Git repository.
