# Java Architecture Diagram and Explanation

## Objective
The objective of this assignment is to understand Java architecture and explain the role of JDK, JRE, and JVM.

## Java Architecture

Java Source Code (.java)
        ↓
Java Compiler (javac)
        ↓
Bytecode (.class)
        ↓
JVM
        ↓
Operating System (Windows/Linux/macOS)

## Components

### JDK (Java Development Kit)
- Used to develop Java applications.
- Contains JRE and development tools.

### JRE (Java Runtime Environment)
- Provides the environment to run Java applications.
- Contains JVM and libraries.

### JVM (Java Virtual Machine)
- Executes Java bytecode.
- Provides platform independence.

## Platform Independence

Java source code is compiled into bytecode. The JVM on each operating system converts bytecode into machine code, allowing Java programs to run on different platforms without modification.
