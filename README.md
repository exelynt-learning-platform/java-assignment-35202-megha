GitHub Workflow
1. Create a GitHub repository.
2. Initialize Git using git init.
3. Add project files.
4. Stage files using git add .
5. Commit changes using git commit.
6. Push changes using git push.



GitHub Issues
GitHub Issues are used to report bugs, request new features, and track tasks in a project.

Pull Requests
A Pull Request is used to request that changes from one branch be reviewed and merged into another branch (usually the main branch).
