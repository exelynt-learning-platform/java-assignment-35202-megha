Java And its history:
Java is high level ,object-oriented programming language developed by games gosling and his team at sun microsystem in 1995;
It was designed with principle ”Write ones run anywhere (WORA)”.
Java is one of the most popular programming language because it is reliable,secure , easy to learn and platform independent.

Features of Java:
1.platform independent: Run on any platform.
2.object-oriented: It supports the oop concepts like class,object,inheritance,abstraction,polymorphism and encapsulation.
3. secure: Java provides the built-in security features.
4.portable:It can change program from one system to another without changing the code.
5.simple: Java has clean syntax and removes complex features.
6.multitreading
7.High performance
